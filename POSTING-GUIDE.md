# Как опубликовать проект: пошагово для первого поста

Ниже — что куда вставлять. Идти по порядку, ничего не пропуская.
Всё, что нужно скопировать, лежит в этой же папке.

---

## Что мы публикуем

1. **Репозиторий на GitHub** — там лежат README, инструкция и скрипты.
2. **Релиз (Release)** — к нему прикрепляется готовый образ `.img.gz` (862 МБ).
3. **Пост-анонс** — на форуме Armbian и/или в 4PDA / Reddit.

Начнём с GitHub: это база, на неё потом будем ссылаться из постов.

---

## Шаг 1. Аккаунт GitHub (если ещё нет)

1. Открой https://github.com/signup
2. Введи email, придумай пароль и **username** (латиницей, например `roma-rk`).
   Username станет частью ссылки: `github.com/roma-rk`.
3. Подтверди email.
4. В настройках профиля (правый верхний угол → Settings → Public profile)
   заполни имя и, если хочешь, аватар. Для первого поста достаточно.

---

## Шаг 2. Создать репозиторий

1. Нажми зелёную кнопку **New** (или https://github.com/new).
2. Заполни:

   | Поле | Что вписать |
   |---|---|
   | Repository name | `h96max-rk3528-armbian` |
   | Description | `Armbian for H96 Max RK3528: Wi-Fi, Bluetooth, GPU and HDMI fixes` |
   | Public / Private | **Public** |
   | Add a README file | **не ставить галочку** (README у нас свой) |
   | .gitignore / license | License → **MIT License** |

3. Нажми **Create repository**.

Ты увидишь пустую страницу репозитория с подсказками — это нормально.

---

## Шаг 3. Загрузить файлы

Самый простой путь — через браузер, без git.

1. На странице репозитория нажми **Add file** → **Upload files**.
2. Открой папку `release/` на компьютере и **перетащи в окно браузера** всё содержимое:
   - `README.md`
   - `INSTALL.md`
   - `POST-github.md`
   - `REPLY-issue.md`
   - `POSTING-GUIDE.md` (этот файл)
   - `SHA256SUMS`
   - `setup-h96max-rk3528.sh`
   - `make-image.sh`
   - папку `files/` (внутри `rk3528-evb2-ddr3-v10.dtb`)
   - папку `scripts/` (внутри `dtb-fix.py`, `bt-init.sh`, `btattach.service`, `bt-init.service`)

   > Папки можно перетаскивать целиком — GitHub сохранит структуру.

3. Внизу в поле **Commit changes** напиши `Initial commit: Armbian fixes and installer`
   и нажми **Commit changes**.

Через несколько секунд файлы появятся в репозитории, а README отобразится на главной
странице — именно его увидят все, кто зайдёт.

**Проверь:** открой страницу репозитория в режиме инкогнито. Должен быть заголовок
«Armbian для H96 Max RK3528», таблица «Что работает» и разделы ниже.

---

## Шаг 4. Создать релиз с образом

1. На странице репозитория справа нажми **Releases** → **Create a new release**
   (или сразу https://github.com/<твой-username>/h96max-rk3528-armbian/releases/new).
2. Заполни:

   | Поле | Что вписать |
   |---|---|
   | Choose a tag | `v1.0` → нажми «Create new tag on publish» |
   | Release title | `v1.0 — Armbian для H96 Max RK3528 (Wi-Fi + BT + GPU)` |
   | Description | скопируй **весь текст** из `POST-github.md` |

3. Ниже, в блоке **Attach binaries**, прикрепи файл
   `h96max-rk3528-armbian.img.gz` (862 МБ).
   GitHub принимает файлы до 2 ГБ — этот проходит.

4. Нажми **Publish release**.

Готово: у тебя есть страница релиза, откуда образ можно скачать,
и постоянная ссылка вида
`https://github.com/<username>/h96max-rk3528-armbian/releases/latest`

---

## Шаг 5. Куда ещё написать (по желанию)

Репозиторий — это «дом». Чтобы о нём узнали, нужен один-два поста.
Не надо писать везде сразу: начни с одного места.

### Вариант А. Форум Armbian (английский)

1. https://forum.armbian.com → зарегистрируйся.
2. Раздел **Community / TV boxes** (или «Community efforts»).
3. Новая тема. Заголовок:
   `H96 Max RK3528 (4/32): Wi-Fi, Bluetooth and GPU working on Armbian`
4. Текст — переведи `POST-github.md` на английский (или напиши коротко):
   что за плата, что починил, ссылка на репозиторий, что не работает (MPP).

### Вариант Б. 4PDA (русский)

1. Найди тему по своей приставке (RK3528 / H96 Max).
2. Напиши сообщение:
   - 5–7 строк о результате (Wi-Fi, BT, GPU работают);
   - ссылку на GitHub-репозиторий;
   - что образ серверный, рабочий стол — по желанию;
   - предложи помочь с другими ревизиями платы.

### Вариант В. Reddit / Habr

- Reddit: r/armbian, r/linuxhardware — короткий пост + ссылка.
- Habr: полноценная статья (текст `POST-github.md` подойдёт почти без правок,
  добавь пару фото приставки и скриншотов `dmesg`).

## Что куда вставлять: шпаргалка

| Куда | Что копировать |
|---|---|
| Поле **Description** репозитория | `Armbian for H96 Max RK3528: Wi-Fi, Bluetooth, GPU and HDMI fixes` |
| Файл **README.md** в репозитории | `README.md` целиком |
| **Release description** | `POST-github.md` целиком |
| **Тема на форуме / в 4PDA** | `POST-github.md`, сокращённый до 10–15 строк + ссылка на репозиторий |
| **Ответ в чужой issue** («работает ли RK3528?») | `REPLY-issue.md` |

## Чек-лист перед публикацией

- [ ] В репозитории открывается README с таблицей «Что работает»
- [ ] В релизе прикреплён образ, ссылка «releases/latest» работает
- [ ] В тексте указано, что образ собран для платы `RK3528_DDR3_8X4_V12` (4/32)
- [ ] Указано, что 4K и аппаратное декодирование в плеерах пока не работают
- [ ] Есть благодарность **ophub** за сборки Armbian и упоминание **DeepSeek Harness**
- [ ] Проверена контрольная сумма образа (`SHA256SUMS`)

---

## Мелочи, которые спасут первый пост

- **Проверь Markdown.** В GitHub есть вкладка **Preview** — нажми и посмотри, что
  таблицы и код отображаются нормально.
- **Не обещай лишнего.** Формулировки «Wi-Fi и Bluetooth работают» подтверждены
  логами, «4K и аппаратное декодирование» — нет. Честность вызывает доверие,
  а завышенные ожидания — злые комментарии.
- **Ссылайся на источник образа.** Armbian для Rockchip собирает ophub —
  упомяни это, чтобы не выглядело, будто образ сделан с нуля.
- **Отвечай на вопросы спокойно.** Первый пост почти всегда приносит
  «а у меня не завелось» — попроси `dmesg` и модель платы, этого обычно хватает.
- **Обновляй по мере правок.** Если кто-то пришлёт рабочий MPP или DTB для другой
  ревизии — допиши в README и выпусти `v1.1`.
